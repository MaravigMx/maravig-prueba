# Maravig · prueba

Primera práctica de GitHub + Cursor.

## Qué es esto

Una página estática (`index.html`) con una tarjeta de departamento.
No es el sitio de producción ni RealHomes. Es el repo para aprender el ciclo:

pedir cambio → ver diff → aceptar → commit → push.

## Cómo verla

Abre `index.html` en el navegador, o en la terminal:

```bash
npx --yes serve .
```
